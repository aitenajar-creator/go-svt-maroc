# نظام SEO التلقائي - Go SVT Maroc

عند كل `push` على `main` يشغّل GitHub Actions الملف `_tools/build_seo.py` قبل نشر الموقع، فيقوم بما يلي:

1. **ينشئ صفحات HTML ثابتة** داخل `/svt/` (صفحة لكل نوع/مسلك/لغة)، مثل:
   - `/svt/examens/fr/2bac-svt/` ← جدول الامتحانات الوطنية (السنوات × الدورات × موضوع/تصحيح)
   - `/svt/cours/fr/1bac-se/` ← دروس 1BAC علوم تجريبية بعناوينها الحقيقية
2. **يعيد كتابة `sitemap.xml`** (الصفحات + ملفات PDF + `lastmod` + `hreflang` عند وجود نسختين عربية/فرنسية).
3. **يملأ الكتلة بين `SEO-LINKS:START` و `SEO-LINKS:END` في `index.html`** بروابط HTML عادية إلى هذه الصفحات (غوغل يتبع `<a href>` ولا يتبع أزرار الجافاسكريبت).

لا حاجة لأي عمل يدوي: ارفع ملفاً جديداً إلى `cours/` أو `exercices/` وستظهر صفحته في الدقائق التالية.

## قواعد مهمة
- **الملفات المكررة** (نفس المحتوى بالضبط) تُحذف من الصفحات تلقائياً.
- **الصفحات التي فيها أقل من ملفين** لا تُنشأ (صفحة شبه فارغة تضر ولا تنفع). تظهر تلقائياً عند إضافة ملف ثانٍ.
- **الملفات الأصغر من 2 كيلوبايت** أو بغير صيغة مستندات تُتجاهل (مثل الملفين الفارغين `Examens Nationaux`).
- أسماء ملفات الامتحانات يجب أن تتبع النمط: `examen-national-svt-...-2023-normale-sujet.pdf`
  (`normale` أو `rattrapage` + `sujet` أو `corrige`) ليُدرج الملف في جدول الامتحانات.

## عناوين الدروس
أسماء مثل `eleves-TCS AIT ENAJAR U1C1.pdf` لا تفيد محركات البحث. اكتب العنوان الحقيقي في `_tools/seo-titles.json`:

```json
"اسم الملف بالضبط.pdf": {"title": "Chapitre 1 : ...", "group": "Unité 1 : ...", "order": 1}
```
(`group` و `order` اختياريان). العناوين الحالية (16) مأخوذة من داخل ملفات PDF نفسها.

## تشغيل محلي (اختياري)
`python3 _tools/build_seo.py` — يحتاج Python 3 فقط. سيعدّل `sitemap.xml` و `index.html` محلياً؛ لا مشكلة إن رفعتهما، فالنشر يعيد توليدهما.

## بعد أول نشر
1. في Google Search Console ← Sitemaps ← أرسل `https://gosvtmaroc.com/sitemap.xml`.
2. في "فحص عنوان URL" اطلب فهرسة: `/svt/` و `/svt/examens/fr/2bac-svt/` و `/svt/examens/fr/2bac-sm/`.
3. بعد أسبوعين راجع تقرير "Pages" لترى ما تمت فهرسته.

# التمارين التفاعلية التلقائية - Go SVT Maroc

عند كل نشر للموقع، يبحث `_tools/generate_quiz.py` عن دروس PDF في مجلد `cours/` **ليس لها اختبار بعد**، ولكل درس:

1. يرسل الـ PDF إلى Claude (يقرأ النص والمخططات والجداول) ويطلب 8 إلى 12 سؤالاً من متعدد، مع شرح لكل إجابة.
2. **يراجع Claude كل سؤال على الدرس نفسه** في تمريرة ثانية، ويُحذف أي سؤال لم يُجزم بصحته.
3. يرفض الكود الأسئلة المعيبة (إجابتان متطابقتان، «كل ما سبق»، بلا شرح...) ويخلط ترتيب الاختيارات.
4. يحفظ الاختبار في `quiz/<اللغة>/<المستوى>/<المسلك>/اسم-الدرس.json` بنفس صيغة اختباراتك اليدوية، فيظهر في قسم **الاختبارات**.
5. يظهر زر **🎯 تمارين تفاعلية** على بطاقة الدرس نفسها (يعتمد على `quiz-map.json`).

يظهر على الاختبار المولَّد «🤖 مولّد آلياً»، ويجد التلميذ بعد كل إجابة رابط **الإبلاغ عن خطأ** يفتح واتساب برسالة جاهزة.

## الإعداد (مرة واحدة)

**1. مفتاح API.** ادخل إلى `console.anthropic.com`، وأنشئ حساباً، واشحن رصيداً صغيراً (Billing)، ثم أنشئ مفتاحاً من **API keys** وانسخه.

**2. أضفه إلى GitHub.** في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**
- Name: `ANTHROPIC_API_KEY`
- Secret: المفتاح الذي نسخته

لا تكتب المفتاح في أي ملف داخل المستودع أبداً.

## التجربة الأولى (درس واحد)

1. **Actions ← Déploiement Go SVT Maroc ← Run workflow**.
2. في خانة `quiz_filter` اكتب `U1C1` ثم **Run workflow**.
3. بعد انتهائه افتح خطوة **Générer les quiz des nouveaux cours** في السجل، وابحث عن سطر يبدأ بـ ✓، وسطر ختامي فيه عدد الرموز (tokens) و«coût estimé».
4. افتح الموقع ← **الاختبارات**، وتحقق من الأسئلة بنفسك قبل التعميم.

## بعد التأكد

- ارفع دروساً جديدة كالمعتاد، أو شغّل **Run workflow** بدون `quiz_filter` لتوليد ما ينقص.
- يُعالَج **5 دروس كحد أقصى في كل تشغيل** لتفادي تكلفة مفاجئة؛ يكمل التشغيل التالي الباقي تلقائياً.

## التحكم

**Settings ← Secrets and variables ← Actions ← Variables** (اختيارية):

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `QUIZ_MODEL` | `claude-sonnet-5-5` | النموذج المستعمل |
| `QUIZ_MAX_NEW` | `5` | أقصى عدد دروس في التشغيل الواحد |
| `QUIZ_VERIFY` | `1` | `0` يوقف المراجعة الثانية (أرخص، وأقل أماناً) |

**تعديل اختبار مولَّد:** افتح ملفه في `quiz/`، واحذف أو عدّل ما شئت من الأسئلة، **واحذف السطر `"auto": true`**. بذلك يصير الاختبار ملكك ولا يلمسه السكربت أبداً.

**اختبار تكتبه بنفسك لدرس معين:** أضف فيه `"source": "cours/francais/.../اسم-الدرس.pdf"`، فلا يولّد السكربت اختباراً لهذا الدرس، ويظهر زر التمارين على بطاقته.

**إذا تغيّر ملف الـ PDF**، يُعاد توليد اختباره آلياً (ما دام `"auto": true` موجوداً).

## التكلفة (تقدير تقريبي)

التسعيرة المعتمدة في وثائق Anthropic لـ Sonnet 5.5: 2 دولار لكل مليون رمز إدخال و10 دولارات لكل مليون رمز إخراج، دون رسوم إضافية للـ PDF. دروسك الحالية 16 درساً بمجموع 200 صفحة، فالتوليد الأول لها كلها بالمراجعة الثانية يُقدَّر بنحو **4 إلى 9 دولارات مرة واحدة**، ثم بضعة سنتات لكل درس جديد. الرقم الحقيقي يظهر في سجل التشغيل («coût estimé») وفي لوحة الاستعمال في Console، فابدأ بدرس واحد وراقبه.

## الخصوصية

ملفات PDF تُرسل إلى واجهة Anthropic API لمعالجتها، ودروسك منشورة أصلاً على الموقع.

## الأعطال الشائعة (في سجل الخطوة)

| الرسالة | السبب والحل |
|---|---|
| `ANTHROPIC_API_KEY absente` | لم يُضف السر، أو كُتب اسمه بشكل مختلف |
| `clé API refusée` | مفتاح خاطئ أو رصيد منتهٍ |
| `modèle introuvable` | تحقق من `QUIZ_MODEL` في لوحة Console |
| `PDF trop long` | أكثر من 100 صفحة: قسّم الدرس إلى فصول |
| `seulement N question(s) fiable(s)` | الدرس قليل المحتوى (غلاف أو تمارين فقط)، أو حُذفت أسئلته في المراجعة |

لا يوقف أي خطأ هنا نشر الموقع؛ يُكمل النشر دائماً بما هو متوفر.

# دليل مراجعة وتطبيق الحزمة محلياً

## النطاق
تتضمن هذه الحزمة ملفات التغييرات المحلية غير المنشورة لمرحلتين من «مجتمع الأساتذة»: الملف المهني، ثم بيانات الموارد التربوية والمفضلة. وهي مبنية على commit الأساس `f6e1d65d3a534e647c189e07c088ce4fa3482e47`.

**هذه الحزمة لا تنشر الموقع ولا تطبق migrations على Supabase.** لا ترفعها أو تنفّذ SQL قبل مراجعة المشروع المستهدف وحالة migrations والنسخ الاحتياطي.

## طريقة الاستخدام
1. أنشئ نسخة احتياطية أو فرع مراجعة من المستودع عند commit الأساس أعلاه.
2. فك ضغط ZIP، ثم انسخ محتويات مجلد `go-svt-maroc/` إلى جذر نسخة المراجعة مع الحفاظ على المسارات. ستستبدل الملفات المعدلة بنسخها المرفقة؛ افحص `git diff` أولاً إذا كان لديك تغييرات محلية أخرى.
3. راجع `docs/PHASE_2_TEACHER_PROFILE_AR.md` و`docs/PHASE_3_RESOURCE_LIBRARY_AR.md` و`TEACHER_COMMUNITY_SETUP_AR.md`.
4. في المستودع بعد نسخ الملفات، شغّل:
   - `npm test` — عند التجهيز المحلي الحالي: 132 اختباراً ناجحاً.
   - `npm run test:browser` — 6 اختبارات ناجحة.
   - `python3 -B scripts/check-site.py`
   - `python3 -B scripts/check-teacher-community-security.py`
   - `python3 -B scripts/check-migration-rls.py`
   - `python3 -B scripts/migration-plan.py --check`
5. لمعاينة الميزات على قاعدة حقيقية، أنشئ staging أو استخدم مشروع المجتمع المؤكد فقط. تحقق من migration history وخذ نسخة احتياطية، ثم اختبر بسياسات RLS وحسابين منفصلين. لا تطبق migrations الخاصة بمشروع `main` على مشروع المجتمع.

## ملاحظات مهمة
- ترحيلا الملف المهني والموارد مضافان إلى manifest لمشروع `teacher-community`، لكنهما **غير مطبقين عن بُعد**.
- لا يحتوي هذا التسليم على مفاتيح سرية أو نسخة من `.env` أو `node_modules`.
- ZIP لتسهيل المراجعة والنسخ اليدوي؛ لم يُنشأ commit ولم يحدث push إلى GitHub.

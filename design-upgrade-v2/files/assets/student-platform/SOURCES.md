# Visual and educational assets

- `learning-hero.png`: original decorative illustration generated for the GO SVT student dashboard. It is a conceptual terrarium illustration, not an experiment photograph or microscope image.
- `learning-hero.webp`: browser-encoded WebP derivative of the original illustration, optimized for delivery. The PNG design source is excluded from the production artifact.
- `cairo-*.woff2` and `fonts.css`: self-hosted Cairo font subsets retrieved from Google Fonts (`https://fonts.google.com/specimen/Cairo`, CSS API `https://fonts.googleapis.com/css2?family=Cairo:wght@400..800&display=swap`). License: SIL Open Font License, included in `FONT-LICENSE.txt` from `https://github.com/google/fonts/blob/main/ofl/cairo/OFL.txt`.
- Schematic course and laboratory drawings: code-generated in `student-platform-art.js` and `student-platform-labs.js`. They are labeled as conceptual diagrams and simplified models.
- `scientific-skills.json`: general scientific-literacy practice authored for this platform. It is not an official national examination or a claim of full curriculum coverage.
- Existing PDFs, exercise files and past-paper files remain unchanged. Their provenance is the supplied repository; this work does not independently certify them as official copies.

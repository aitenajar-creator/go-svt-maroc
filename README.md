# Go SVT Maroc - مختبر علوم الحياة والأرض

منصة تعليمية متكاملة لعلوم الحياة والأرض لجميع المستويات الدراسية في المغرب.

## 🌟 المميزات

- **واجهة عربية كاملة** - تصميم يدعم اللغة العربية من اليمين إلى اليسار
- **ثنائية اللغة** - محتوى بالعربية والفرنسية
- **تنظيم شامل** - دروس، تمارين، وملاخصات لجميع المستويات
- **تصميم متجاوب** - يعمل على جميع الأجهزة (الكمبيوتر، التابلت، الهاتف)
- **تنقل سهل** - قائمة تنقل سلسة بين الأقسام
- **تصميم عصري** - ألوان جذابة وتصميم احترافي

## 📚 الأقسام الرئيسية

### 1. الرئيسية (Accueil)
- صفحة ترحيبية
- ميزات المنصة
- أزرار للوصول السريع

- دروس بالعربية والفرنسية

- بطاقات مذاكرة

### 5. الوثائق التربوية (Documents pédagogiques)
- البرامج الدراسية الرسمية
- المناهج التربوية
- دليل المعلم
- نماذج الامتحانات

### 6. الموارد المدرسية (Ressources scolaires)
- الموارد العلمية
- الفيديوهات التعليمية
- الأدوات التفاعلية
- المكتبة الرقمية

### 7. متفرقات (Divers)
- المسابقات
- أخبار علمية
- نصائح دراسية
- التوجيه المهني

### 8. اتصل بنا (Contact)

- معلومات الاتصال
- روابط التواصل الاجتماعي

## 📤 إضافة الملفات (أوتوماتيكي!) ⚡

**ممتاز! النظام الآن أوتوماتيكي بالكامل!**

كل ما عليك فعله:
1. اذهب إلى GitHub: https://github.com/aitenajar-creator/go-svt-maroc
2. ارفع الملفات في المجلد المناسب
3. اضغط "Commit changes"
4. انتظر دقيقة - وستظهر الملفات تلقائياً في الموقع!

**لا حاجة لتعديل أي كود!** 🎉

للمزيد من التفاصيل، راجع ملف `HOW_TO_ADD_FILES.md`

**مثال:** لإضافة درس بالفرنسية لمستوى TC TCS:
```
cours/francais/TC/TCS/ملف_الدرس.pdf
```

## 🔧 التخصيص

### تغيير الألوان
في ملف `styles.css`، عدل المتغيرات في `:root`:
```css
:root {
    --primary-color: #2c5f2d;
    --secondary-color: #97bc62;
    --accent-color: #ffc107;
    /* ... */
}
```

### إضافة محتوى جديد
في ملف `script.js`، أضف البيانات إلى `siteData`:
```javascript
const siteData = {
    cours: {
        francais: {
            TC: {
                TCS: [
                    { title: "عنوان جديد", description: "وصف الدرس" }
                ]
            }
        }
    }
};
```
